ML + NLP + GenAI Recommendation Pipeline

One script (scripts/05_analyze_and_generate_emails.py) — reads campaign + market data, analyzes it with three distinct tech stacks, and drafts a response-optimized customer email.

SYNTHETIC DATA — ILLUSTRATIVE ONLY

Inputs

  • input/campaigndata-campaigns.csv — 22 campaigns across 3 pilot accounts
  • input/campaigndata-keywords.csv, search_terms.csv, negative_keyword_conflicts.csv, ads.csv, auction_insights.csv — keyword / query / ad-strength / competitive-position grain
  • input/marketdata-*.pdf — 4 fictitious vendor research reports

Outputs (per account)

  • output/{account}_full_result.json — every stage's structured result
  • output/recommendation_email_*.pdf — the finished customer email
  • output/validation_report.md — token usage + per-account summary

The flow

ML (scikit-learn / scipy) NLP (TF-IDF + cosine similarity) GenAI (OpenAI, structured output) Deterministic Python
1

Read input data

Load input/campaigndata-campaigns.csv.

2

Pre-processing

Slice to one account, derive the missed-impressions column.

3

EDA / ML analysis ML

Pearson correlations, IsolationForest anomaly scores, KMeans clusters, materiality ranking — plus keyword/search-term/negative-keyword/ad-strength/auction-insight evidence, the deeper grain a real analyst digs through.

4

Parse market PDFs

Real pdfplumber table extraction from the 4 vendor PDFs.

5

Pydantic schemas

Structured-JSON contract for every GenAI call.

6

GenAI: ads-data analysis GenAI

One OpenAI call forms its own diagnosis from the raw data + all of step 3's evidence — produces prioritized recommendation cards and an "already working" list, not just a paragraph.

7

NLP: relevance ranking NLP

TF-IDF + cosine similarity scores every extracted market fact against this account's diagnosis text; only the closest matches move on.

8

GenAI: market mapping GenAI

One OpenAI call builds the "why now" case from the NLP-shortlisted facts, AND independently maps market evidence onto each individual recommendation (a fact per card, only where one genuinely applies) — the 360° step a human analyst can't do alone.

9

GenAI: email copy GenAI

One OpenAI call drafts the persuasive copy (hook, bullets, CTA) — the deeper evidence from step 6 renders directly, this call writes the connective tissue around it.

10

Render PDF

Build the email as a real PDF, reusing existing reportlab layout helpers.

11

Validation report

Token/cost totals + a per-account summary.

Model: one OpenAI model constant for every GenAI stage (single-provider by design — a future model/provider swap is a one-line change). Deterministic revenue and opportunity-sizing numbers are computed in Python, never invented by the LLM. Everything in this pipeline's output is synthetic / illustrative.
